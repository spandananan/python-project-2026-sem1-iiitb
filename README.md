# Python Project IIITB


## How to run

### Frontend

Open linux terminal in project directory and run

```bash
cd EMS
npm run dev
```

### Backend

Open another linux terminal in project directory and enter following commands

```bash
  cd server
  source .venv/bin/activate
  uvicorn main:app --reload
```
